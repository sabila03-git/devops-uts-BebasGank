# DevOps UTS - Implementasi End to End

## Deskripsi Proyek
Proyek ini merupakan implementasi DevOps end-to-end untuk mata kuliah 
Development Operations (DT206) di Universitas AMIKOM Yogyakarta.

## Fitur Login
Fitur login telah ditambahkan pada aplikasi web ini.
Fitur ini mencakup:
- Autentikasi pengguna
- Validasi form login
- Session management

## Tech Stack
- Node.js / PHP
- Docker
- Jenkins / GitHub Actions
- Terraform
- Kubernetes
